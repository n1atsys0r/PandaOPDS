# 订阅与下载任务

订阅按计划从预设或自定义关键词抓取出版物，并把记录累积在 SQLite 中供本地检视。抓取本身不下载归档，也不消耗账户 GP。每轮读取上游一页，记录会跨轮累积；重复作品按订阅与作品身份去重。多个订阅的合并视图也会去重展示同一作品，同时保留它所属的订阅。

可订阅的预设包括最新发布、热门画廊、关注更新、排行榜和收藏夹。收藏夹不再由系统自动创建特殊订阅；用户可以选择「全部收藏」或单个收藏夹预设自行追新。每轮只请求最新一页，不遍历完整收藏历史，也不与收藏夹写操作联动同步。

作品分类筛选可用于关键词搜索、最新发布、关注更新、热门、排行榜和收藏预设。上游支持时，搜索、最新发布和关注更新会使用分类请求参数；热门、排行榜和收藏预设在收到结果后按分类过滤。留空表示包含全部分类。已有缓存记录会保留，并按当前分类选择筛选展示。

首次抓取建立订阅的缓存基线，不会自动归档基线中的既有作品。后续新发现记录可按订阅设置自动归档；自动归档默认禁用，启用后可能消耗账户 GP。归档费用与任务安全规则见[归档](archive.md)。

订阅也可在「编排」中作为 `subscription` 来源，用于 Publications 预览或导航入口。选择订阅后，OPDS 页面读取其 SQLite 累积条目并提供分页目录，不会因客户端访问而即时抓取。

关键词支持 EH 搜索语法，例如 `l:chinese expunged -o:"rough translation$" -o:"extraneous ads$"`；高级控制词会作为上游筛选参数处理，引用短语保持原样传递。订阅修改查询或分类时会创建新 revision，旧请求不能覆盖新条件的状态。

下载任务状态、订阅配置和缓存条目通过 [`api/openapi.json`](../api/openapi.json) 中的 `/api/subscriptions`、`/api/subscription-items` 与 `/api/download-jobs` 接口访问。收藏添加、移动、移除仍由 `/api/favorites` 代理上游。

「清理已检视」与「清理已隐藏」会从订阅列表中移除相应条目，并保留成员去重 tombstone；它不会删除 publication、封面、归档文件、进度或下载任务。清理操作要求显式确认。人工批量下载最多接受 200 项，要求请求明确确认；服务会先验证整批输入，再逐项进入独立任务列表。单项错误不会隐藏其他项的接受结果，已存在的运行任务会返回原任务 ID。

升级时，旧的系统收藏订阅会迁移为普通收藏夹预设，并保留已有缓存与基线。旧配置中的收藏夹目录自动归档规则不再适用；如果旧订阅设置过此类规则，迁移会关闭其自动归档，避免规则转换后扩大归档范围。
