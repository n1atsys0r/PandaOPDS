# 订阅与下载任务

订阅定期从预设或自定义关键词抓取出版物列表，并把结果缓存在 SQLite 中供本地检视。抓取本身不下载归档，也不消耗账户 GP。检索列表可按关键词与分类筛选，多个订阅的合并视图会去重展示同一出版物，同时保留它所属的订阅。

已创建的订阅可在「编排」中作为 `subscription` 来源，用于 Publications 预览或导航入口；选择订阅后，OPDS 页面读取其 SQLite 累计条目并提供分页目录，不会因客户端访问而即时抓取。此方式适合更新频率较低的 Popular、Toplist 等订阅。缓存保留规则会保留先前成功抓取的条目，因此目录反映订阅目前累计保存的结果。

内置「EH 收藏」订阅承接旧收藏夹同步。首次同步建立基线，只记录已存在的条目；基线不完整时不会把未扫描到的收藏误判为新作品并自动购买。修改订阅查询会创建新 revision，旧请求不能覆盖新条件的缓存或完成状态。收藏分类范围（`query.favorite_categories`）控制哪些收藏进入订阅；自动下载规则中的 `categories` 与 `excluded_categories` 单独控制哪些新条目可排队下载。

关键词订阅和「最新发布」预设每次（包括立即抓取和定时抓取）只读取上游一页，不继续翻页补齐历史；每页条目数由上游决定，不固定为 25。已缓存记录会保留。收藏夹订阅仍按其分页预算同步。关键词支持 EH 搜索语法，例如 `l:chinese expunged -o:"rough translation$" -o:"extraneous ads$"`；高级控制词会作为上游筛选参数处理，引用短语保持原样传递。

旧收藏同步可能只有图库身份、没有标题等元数据；这类记录保留为同步基线，不计入列表和分页，后续抓取补齐标题后才显示。列表封面统一通过本地接口加载，首次访问从上游取得并存入 SQLite，之后使用本地缓存。已经完成迁移的数据库也适用，无需重新导入旧数据。

自动下载默认关闭。启用后，服务在每个任务开始前重新验证订阅仍启用、条目属于当前 revision、来源授权的档位、收藏分类规则及本地删除抑制。队列中的来源可撤销；已经开始的任务不会因订阅改动而被静默取消。手动下载也进入独立任务列表。结果不确定时任务标为 `needs_review`，不会自动重复购买。用户可在复核时先查询并关联已经存在的文件；选择允许重试时必须明确确认，该操作只关闭旧任务，不会自动重新购买，后续需重新手动报价和提交。

下载任务状态、订阅配置和缓存条目均通过 [`api/openapi.json`](../api/openapi.json) 中的 `/api/subscriptions`、`/api/subscription-items` 与 `/api/download-jobs` 接口访问。旧 `/api/favorites/sync` 路径保留为兼容入口，收藏写操作仍直接代理上游；订阅数据库是本地收藏成员关系和同步状态的唯一权威来源。

「清理已检视」与「清理已隐藏」会从订阅列表中移除相应条目，并保留成员去重 tombstone；它不会删除 publication、封面、归档文件、进度或下载任务。清理操作要求显式确认。人工批量下载最多接受 200 项，要求请求明确确认；服务会先验证整批输入，再逐项进入独立任务列表。单项错误不会隐藏其他项的接受结果，已存在的运行任务会返回原任务 ID。
